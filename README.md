# Proyecto Modelo de Clasificacion de Imágenes usando DL


Este proyecto corresponde a el trabajo de grado para la carrera de biotecnologia

##Objetivo
El objetivo principal es desarrollar un modelo de redes nueronal convolcionales (CNN) que puedan determinar la morfología del núcleo celular, el aspecto de la matriz extracelular, la intensidad de la coloración de la tinción con safranina-O y la inmunotinción específica para colágenos tipo I, colágeno II y agrecano I
